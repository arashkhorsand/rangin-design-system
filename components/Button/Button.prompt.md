# Button

دکمهٔ قرصی برای هر اقدام؛ در هر نما فقط یک دکمهٔ اصلی سبز.

`<button class="rg-btn rg-btn-primary">`. شما برچسب (یک فعل) و در صورت نیاز یک آیکون ۲۰ پیکسلی درون دکمه می‌دهید.

| کلاس | کاربرد |
| --- | --- |
| `rg-btn-primary` | اقدام اصلی صفحه. `brand` با متن `on-brand` و سایهٔ `glow-brand`. |
| `rg-btn-ink` | اقدام اصلی دوم یا پرداخت نهایی. |
| `rg-btn-pink` | کمپین و تخفیف. کنار `rg-btn-primary` نگذارید. |
| `rg-btn-tint` | اقدام فرعی کم‌وزن. |
| `rg-btn-outline` | انصراف و اقدام خنثی. |
| `rg-btn-danger` | حذف و لغو برگشت‌ناپذیر. |
| `rg-btn-sm` · `rg-btn-lg` | ارتفاع ۳۶ و ۵۶؛ پیش‌فرض ۴۸. |
| `rg-btn-block` | تمام‌عرض، برای پایین صفحهٔ موبایل و شیت. |
| `rg-btn-icon` | فقط آیکون؛ `aria-label` بدهید. |

- برچسب فعل است: «افزودن به سبد»، نه «تأیید».
- آیکون جهت‌دار در راست‌به‌چین رو به چپ است.
- `rg-btn-sm` را برای اقدام اصلی موبایل به کار نبرید؛ هدف لمسی ۴۸ پیکسل است.
- غیرفعال: `disabled` یا `aria-disabled="true"`.
